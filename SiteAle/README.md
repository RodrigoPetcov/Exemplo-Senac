# SiteAle

Landing page para personal trainer (temática moderna e feminina).

Seções: menu superior fixo, início (hero), sobre mim, serviços, como funciona, depoimentos, chamada para ação, perguntas frequentes, contato (formulário que abre o WhatsApp) e rodapé, além do botão flutuante de WhatsApp.

## Como usar
Abra o `index.html` no navegador. Não precisa de build.

## Personalizar
- Telefone do WhatsApp: `script.js` (`WHATSAPP`) e o link `wa.me` em `index.html`
- Textos, CREF, e-mail e Instagram: `index.html`
- Cores: variáveis em `:root` no `style.css`
- Fotos: troque as URLs das tags `<img>` por fotos reais da personal
